## 💻 What This Tool Does

SCUM Modding Studio is built around a simple idea: let ordinary players reshape the game world without learning professional game development software. Everything happens inside one window, with a 3D view of the island and straightforward panels for the things you want to change.

### 🏝️ 3D Island Editing

The centerpiece is a live three-dimensional view of the SCUM island. You can fly the camera around the terrain, look at locations from any angle, and make changes while seeing the results immediately. There is no need to load a separate editor or convert files by hand — the island appears on screen the moment you open a project.

Terrain editing lets you raise and lower ground, smooth out rough areas, and prepare flat spaces where new content will sit. Because the view is fully 3D, you can check how a hillside or coastline will look in-game before you ever launch the game.

### 🌉 Building Bridges and Roads

Bridges and roads are some of the most requested additions in the SCUM modding community, and this tool treats them as first-class features. You can draw a route across water or rough ground, place bridge segments piece by piece, and connect road sections so they line up cleanly with the existing landscape.

The editor shows you the full path as you build it, so you can adjust curves, heights, and connection points without guessing. When you are finished, the finished route becomes part of your mod and appears in the game exactly where you placed it.

### 🚗 Vehicles and Weapons Tuning

SCUM Modding Studio includes a tuning area for vehicles and weapons. You can adjust values such as speed, handling, durability, damage, and other gameplay numbers using simple controls rather than editing configuration files.

The cloning feature is especially useful. If you like an existing vehicle or weapon and want a variant of it, you can duplicate the original and then change only the details you care about. This lets you create a whole family of related items — a faster version of a car, a heavier version of a rifle — without rebuilding anything from scratch.

### 📦 Exporting Mod Paks

When your work is done, the studio packages everything into a mod pak file. That single file is what the game reads. You can use the pak in your own single-player world, or hand it to a server owner so it can be loaded on a multiplayer server.

The export process is handled by the application, so you never have to deal with archive formats, folder structures, or packaging commands. Choose an export location, confirm, and the pak is ready.
